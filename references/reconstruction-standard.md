# 重建与可编辑性标准

## 1. 可编辑性的含义

“可编辑”表示用户能在 Photoshop 中单独选择、隐藏、移动、缩放、调色、替换或修改一个元素，而不影响无关元素。

| 元素 | 首选表示 | 可接受替代 |
|---|---|---|
| 可见文字 | 实时文字层 | 无 |
| 矩形、圆形、线条、边框 | 形状图层 | 独立像素层 |
| 阴影、描边、发光 | 图层样式 | 独立效果层 |
| 照片、人物、商品 | 带蒙版智能对象 | 隔离像素层 |
| Logo、二维码、图标 | 矢量或透明智能对象 | 高分辨率隔离智能对象 |
| 复杂插画、吉祥物 | 嵌入智能对象 | 独立透明像素层 |
| 色彩处理 | 调整图层 | 智能滤镜 |

独立像素层能满足移动、隐藏、变换和调色，但不是参数化矢量；交付时如实说明。

## 2. 原图使用规则

- 原图只作参考，不得成为默认可见输出底图。
- 如需保留，放入隐藏的 `00_REFERENCE_DO_NOT_EXPORT` 分组。
- 照片区域含嵌入文字时，先清除、裁掉或重建该区域，再添加实时文字。
- 不允许用同色块只覆盖旧字的局部；更换更短或更长的文案时也不能露出旧字。

## 3. 元素清单

重建前建立：

`id | type | content | left,top,right,bottom | style | representation | group | confidence`

坐标不确定时先用标准化坐标。重复圆卡、表格或商品卖点先记录中心点和公共尺寸，再生成实例。

## 4. 排版重建

逐项保留：

- 标点、全角符号、英文大小写；
- 数字、单位、范围符号和换行；
- 字体角色、粗细、字号、行距、字距、颜色和对齐；
- 标题、正文、注释和标签之间的层级。

原字体缺失时，优先匹配文字轮廓、宽度、字高和粗细，禁止为了塞进版面而任意横向拉伸。

## 5. 几何重建

- 先测量画布、页边距、栏宽、中心点、行列间距和关键基线。
- 重复卡片分别编号，保证每个实例可以单独调整。
- 使用新建文档的底色、色块和圆形；不要从完整海报裁下一大块充当几何背景。
- 图层创建顺序按 Photoshop 的实际插入行为验证。脚本通常会把新分组插到顶部，因此应按底部到顶部创建。

## 6. 智能对象边界

复杂素材作为智能对象表示：

- 能独立移动、缩放、隐藏和替换；
- 内部可能仍是栅格图像；
- 不等于内部所有线条、颜色或图案都已矢量化。

如果用户要求复杂 Logo 或插画内部也逐路径编辑，需要另行矢量重绘，而不是继续称其为普通海报拆层。
